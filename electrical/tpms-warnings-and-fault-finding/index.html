    TPMS warnings and fault finding

    Tags: #tpms · #tire-pressure

    Detail card of the overview TPMS tire pressure sensors.

    • Low-pressure warning. Pressing OK on the steering wheel only acknowledges it for now; if it returns after the next ignition cycle, pressure really is below spec, so check and inflate 12.
    • "Check TPMS system" (проверяйте систему TPMS). Usually means the batteries in the wheel sensors are exhausted (Victor, October 2026); the dashboard photo at 42,657 km shows the yellow warning with a tyre icon and a "stop reminder" prompt 3. The sensors are potted and cannot be opened, so owners replace them and clone the IDs 45. Dead sensors cannot broadcast their IDs, so reviving them is pointless: read the ID printed on each sensor, or with an OBD2 scanner, and have a tyre shop program the new sensors with those IDs when the wheels are mounted 67.
    • Dead-sensor warning (2026). The warning appears when a wheel sensor stops reporting and the dashboard shows which wheel has no reading. One owner said only replacing the sensors clears it 8; another said the only way to remove it is to make the sensors work 9; a third pointed to the cabin fuses without explaining how, which is unclear 10.
    • After a car wash. Try resetting through the dashboard menu, then disconnect and reconnect the battery terminal; if it persists suspect a dead sensor battery or failed sensor. One thread names a CR2032-type cell, others CR2450/BR2450 (see TPMS sensor battery life and replacement); because opening a sensor takes knife-and-soldering-iron skill, the practical fix is usually replacing all four together for consistent recalibration 1112131415161718.
    • All dashes/blank on the trip computer with the light on. Check in order: sensors physically present on all four wheels; sensor battery status (most common failure near the ~5-year mark); physical sensor damage. None can be confirmed without removing the wheels, as there is no non-invasive diagnostic for individual sensors 192021222324252627.
    • Intermittent signal loss can come from a weak end-of-life battery (~6 years), poor contact at the receiver module, or the normal registration delay 282930. Cold can cause temporary failures that recover after about 10 km of driving 3132333435.
    • "Info" button unresponsive / no data. A new owner of a manual-transmission restyle X80 found neither parking nor tire-pressure sensors working, and the "i" button, which should open the tire-pressure menu, did nothing 3637. Others see the menu open but show no readings, so there are two failure modes: the menu does not open, or it opens empty 3839. Community advice: first decide whether the button itself is faulty, since a working button with blank data points to dead sensors/batteries; complete failure needs a scanner 404142. One owner ordered new sensor batteries to troubleshoot before a full swap 4344.
    • Battery-only service. A lower-confidence report says some sensors can be serviced by changing the internal battery, and some owners simply ignore the light as a non-critical convenience; either way re-registration needs technician-grade equipment 454647484950.
