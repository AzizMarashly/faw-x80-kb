    Видео на мультимедийной магнитоле

    Теги: #infotainment

    Штатная мультимедийная магнитола воспроизводит видеофайлы в формате MP4 — подтверждено владельцем, который закачивал мультфильмы дочери для просмотра в дороге 1.

    По умолчанию в магнитоле включена блокировка видео при движении: видео останавливается/гаснет, как только автомобиль начинает двигаться — типичное поведение безопасности для штатных магнитол китайского рынка. Это можно отключить через меню настроек, чтобы видео продолжало воспроизводиться в движении — один из владельцев прислал скриншот именно этого меню (переключатель Enable/Disable, под ним строка "ON ▶"), до которого нужно дойти через настройки магнитолы, хотя точный путь до этого экрана в сообщении не был расписан 2. Исходный вопрос о разрешении экрана и поддерживаемых форматах остался без ответа по разрешению — только по формату и этому обходному пути 3.

    Медиа

    Фото сенсорного экрана мультимедиа с подменю настроек, где виден переключатель "Enable / Disable" (выделено Enable) и строка "ON ▶" под частично закрытой рукой подписью настройки; это тот самый экран, который используют, чтобы видео продолжало воспроизводиться при движении автомобиля.
