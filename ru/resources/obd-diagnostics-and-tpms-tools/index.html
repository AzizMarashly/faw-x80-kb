    OBD-сканеры, диагностическое ПО и инструменты TPMS

    Теги: #obd · #diagnostics · #scanner · #tpms · #elm327 · #battery

    Цены и поставщики на этой странице — российский рынок (RUB, на указанные даты).

    ПО/платформа. Diagzone (экосистема X431) — основное диагностическое ПО в сообществе; подписка Diagzone Pro покрывает 650+ марок автомобилей, включая X80 12. Работает в связке с недорогим свистком Mucar BT200 (Wi-Fi/OBD), перепрошитым под бэкенд Diagzone — в этом случае читает всю машину, а не только двигатель 12. Для корректного чтения рестайлинговых моделей (2019+) нужен модуль "FAWCARS" для Diagzone с актуальными обновлениями 3. Android-приложение CarMin содержит электросхемы X80, отдельно от любого сканера 4.

    Варианты железа. - Mucar/Makar BT200 + Diagzone Pro: базовый бюджетный вариант сообщества, ~8 000 руб. за один свисток (рынок РФ, октябрь 2024) 5; требует прошивки под Diagzone (либо доплаты 8 000–10 000 руб. (рынок РФ, октябрь 2024) за уже прошитый экземпляр) для полной диагностики всей машины 6. Без прошивки читает только коды двигателя (ECU), и то не на всех моделях 7. Для диагностики коробки передач/электрики рекомендуется профессиональная диагностика в сервисе (с диагностом, а не только сканером) 8. На 2024-12-27 цена минимального рабочего комплекта в сообществе: свисток Mucar BT200 (~10 000–25 000 руб. розница) + ПО/модуль Diagzone/FAWCARS (~720 руб.) (рынок РФ, декабрь 2024) + смартфон/планшет для запуска 9. Несколько участников купили устройства по ссылкам Ozon, которыми делились в чате примерно в это время 10. - Thinkdiag 2: альтернативный сканер первого поколения, использующий тот же сервер/базу данных, что и прошитые под Diagzone Mucar-устройства, поэтому должен поддерживать тот же список авто 11. - Autel TS508: отдельный специализированный инструмент — не универсальный OBD-сканер — используется конкретно для программирования/клонирования датчиков TPMS 12. - ELM327 Bluetooth Mini v1.5 (товар Ozon 929042666): дешёвый обычный Bluetooth-адаптер OBD2, подтверждённо без проблем подключается к X80 13. Рекомендуемые бесплатные приложения: Car Scanner или ScanMaster 14. Ограничение: такой класс адаптеров читает и сбрасывает только коды двигателя (ECU) по протоколу OBD2 — не читает пробег, статус подушек безопасности и прочие данные блоков кузова 15. Тот же класс обычного адаптера ELM327 независимо подтверждён и для чтения автомобилей Opel и Skoda, а не только FAW — то есть это не устройство, специфичное для FAW 16.

    Расположение разъёма OBD-II. Под рулём, немного правее центра, смотрит вниз. Снимать пластик/накладки для доступа не нужно 1718.

    Адаптеры ELM327 — отдельный бюджетный класс, не Diagzone/Mucar. Помимо экосистемы Diagzone/Mucar выше, обычные клоны ELM327 — стандартный бюджетный вариант, который многие держат просто в бардачке: устройство "ELM327 OBD2 WI-FI v1.5, чип PIC18F25K80" с Ozon (https://ozon.ru/t/ynzRtEQ) работает с бесплатным приложением Car Scanner для Android 1920. Надёжность нестабильна — качество клонов ELM327 — "лотерея": у одного участника адаптер подключался через раз и отваливался каждые 5 минут — признан непригодным, у другого тот же класс адаптера работает без проблем с 2015 года, третий заказал версию 2.1 в надежде на удачу 212223. Цена достаточно низкая (~900 руб. (рынок РФ, март 2024)), так что замена неисправного экземпляра не критична 22. - Car Scanner ELM OBD2 (Google Play: com.ovz.carscanner) — предпочитаемое сообществом бесплатное приложение по сравнению с альтернативой OBD Mari, по опыту владельца, пробовавшего оба 2425. Показывает показания лямбда-зонда, нагрузку на двигатель, давление во впускном коллекторе, долго- и кратковременную коррекцию топлива, температуру охлаждающей жидкости и обороты холостого хода, плюс чтение/сброс кодов ошибок двигателя 2526. - Жёсткое ограничение, подтверждённое независимо двумя разными владельцами: обычный ELM327 читает и сбрасывает только коды двигателя (ECU) — не читает блок подушек безопасности, блок АКПП (AISIN AKPP) и прочие данные блоков кузова, что совпадает с уже упомянутым ограничением ELM327 Bluetooth Mini выше 2728. Не существует Android-приложения, показывающего специфичные для X80 параметры сверх стандартных PID OBD2 — на прямой вопрос в чате был дан однозначный ответ "нет" 2930. - Ложные коды из-за разряда аккумулятора. Слабая/разряженная батарея может спровоцировать волну одновременных кодов ошибок (в т.ч. по АКПП), которые сами исчезают после подзарядки/переподключения аккумулятора. У одного участника загорелась подушка безопасности, он поехал в сервис, ему показали длинный список кодов ошибок, и он заплатил 1 500 руб. (рынок РФ, февраль 2026) за "диагностику", которая оказалась именно этим — полностью разряженным аккумулятором, а не реальной неисправностью; после этого он купил дешёвый адаптер ELM327 на AliExpress, чтобы впредь проверять коды самостоятельно, и с тех пор ошибок на нём не видел 3132. Второй, независимый отчёт подтверждает этот паттерн: у другого владельца АКПП выдала код ошибки по низкому напряжению после разряда батареи, и код так же исчез после решения проблемы с батареей 33. - Для стирания (а не только чтения) кодов может понадобиться "двухплатный" ELM327. Один участник, купивший расширенный ELM327 (с чипом и ПО для компьютера/телефона) несколько лет назад, отметил, что для стирания кодов ошибок нужна версия адаптера "2-плата" (с двумя печатными платами) — это должно быть явно указано в описании товара; однобортовый (одноплатный) адаптер, судя по всему, может читать, но не надёжно стирает коды 34. - FCAR CW700 — отдельный профессиональный OBD2-сканер для китайских марок (Chery, Haval, Geely, Changan) с полной диагностикой всех систем и бесплатными обновлениями; предложен как альтернатива, когда ELM327 не хватает, продаётся на Ozon (https://ozon.ru/t/b2ThFxa) 35.

    TPMS (датчики давления в шинах). - Батарейки датчиков обычно запаяны внутри корпуса и не предназначены для замены пользователем, однако есть видео с практическим способом вскрытия датчика и замены батарейки 36. - Объявление услуги на Avito от исполнителя в Москве: профессиональное программирование, клонирование и адаптация датчиков TPMS — актуально для тех, кто покупает generic/б.у. датчики и должен привязать их к машине 37. - Видео на RuTube показывает установку и программирование датчиков TPMS для X80, включая адаптацию универсальных (неоригинальных) датчиков 3839.
