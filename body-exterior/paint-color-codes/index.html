    Paint color codes — location and known values

    Tags: #paint

    Prices and suppliers on this page are Russian-market (RUB, at the dates shown). Verify locally before relying on them in Syria.

    The car's paint color code is located on the door jamb or the driver-side pillar specification plate. Color shops use this code to mix matching paint for repairs 1234.

    Known codes reported by owners: - A4D — Arctic White, for 2018+ FAW X80 models 56. - 32V — Agate Red, factory spec for certain model years 2. - A4D (Arctic White, Acrylic) is also catalogued under paint code RF1000-1; this white is reported prone to fading over time, so professional color-matching is recommended for touch-up/repair work rather than assuming an off-the-shelf match 7891011. - 7В KNIGHT BROWN metallic pearl xerallic — nominal/documented standard color code, also identified as "Coriander 790" in a separate reference (a previous Lada Granta owner recognized the same shade). In practice, professional painters rarely rely on the code alone — they typically pull a reference part (e.g. the fuel filler door or a bumper section) and match by physical shade/tone/sample rather than trusting the code number, since a physical color-chip match is more reliable 1213. - 41v — a soul-red shade, used from approximately the 2018 model year onward as the standard factory finish for red units 141516. - 41V — independently corroborated: FAW-CAR's official name for this code is "Soul Red" (solid, not metallic), listed by a seller as used across 2014–2023. A touch-up correction pen for chips/scratches in this color is available via Ozon 17.

    Finding your color code — fuel-door label method: to determine the X80's exact paint color code, remove the fuel-filler door cap/cover and check the color label on its interior surface — the label states the factory paint specification for exact matching 1819.

    Knight Brown touch-up paint — sourcing (Nov 2025): a base + clear-coat touch-up kit for the FAW Besturn X80 brown/Knight Brown color is available in a 40 mL size from the CarBase supplier. One owner ordered it via Ozon, which was ~100 RUB cheaper than WildBerries for the same kit (Nov 2025, RU market). An alternative aerosol option is SKULL Aerosol Enamel "Coriander" metallic (520 mL) — but since it's a straight color coat, a separate clear coat must be applied afterward for durability 2021222324.

    Factory red = Mazda V32 "Agatred": after trying to color-match X80 red against Chinese-market swatches and doing test spray-outs, one painter found the correct match was much simpler — the X80's factory red is identical to Mazda color code V32 (Agatred). This lets owners source matching touch-up/repaint paint from Mazda-parts suppliers rather than FAW-specific channels 25. This appears to be a different/updated reference to the same red covered by code 41v above — cross-check both codes against a physical color-chip match before ordering paint.

    Additional factory color codes and no dashboard badge confirmation: further confirming the fuel-door label method above (no dashboard color badge exists on the X80), the following FAW factory color options were additionally reported: 38P LIGHT SILVER (metallic), B06 FLASH RED (pearl) — in addition to the 32V Agate Red, 7B Knight Brown, and A4D Arctic White codes already listed above. As with the other colors, Mazda paint codes are also usable for color-matching on red variants 262728293031.

    Knight Brown touch-up kit — additional confirmation (March 2026): a 40 mL base + clear-coat touch-up kit specifically for 7B KNIGHT BROWN is available on OZON, confirming/matching the November 2025 sourcing note above — recommended for small chips and scratches 32.

    Touch-up kits — practical application results and metallic-paint limitations: touch-up kits (FixPaint Double brand or similar) are available on Ozon and Wildberries. One user reported that a 7B-brand paint matched perfectly, while metallic paints from other kits are impossible to apply evenly with a brush — for proper metallic color correction, professional painter application is recommended. Small touch-ups in inconspicuous areas work adequately with brush-applied kits; full door repainting is often necessary for visible areas 33343536373839.

    A7 "Huanying Black" — pre-facelift black code: for the black pre-facelift (2012–2017) Besturn X80, the reported paint code is A7 "Huanying Black" (Oley paint type). This is in addition to the red (32V "Agate Red", restyled 2018+) and other codes listed above; codes for white and other colors are also in circulation but reported as prone to variation — custom color matching is recommended when replacing body panels 4041424344.
