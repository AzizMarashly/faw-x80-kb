    Parking brake light stuck after pad replacement

    Tags: #parking-brake

    Prices and suppliers on this page are Russian-market (RUB, at the dates shown). Verify locally before relying on them in Syria.

    Replacing brake pads with the ignition ON, then turning the ignition OFF while the electronic parking brake solenoids are still powered, can leave the parking brake warning light stuck ON. This is a control-module error state, not a hardware fault123. Fix: connect an OBD diagnostic scanner to clear the error / reprogram the control logic45. Note: some local dealerships lack the proper diagnostic equipment and cannot read or clear this system's errors — a specialist with an appropriate scanner may be required67.

    Second documented case — likely trigger is skipping a sensor-reset step. Another owner replaced front and rear brake pads all around before a road trip and forgot about the parking brake, which then entered service mode — likely because the brake-pad sensor reset procedure was missed during the pad change8. The owner tried several independent auto-electricians first; some did not have this vehicle in their diagnostic tool's database and others simply warned the handbrake unit might be ruined, so none could resolve it8. The official FAW dealership was ultimately able to clear the error code directly, confirming again that dealership tooling — not general aftermarket scanners — is what's needed for this system. Cost: 5,250 RUB for the wash/diagnostic visit that included the code clear (2026-07, Russia)8.
