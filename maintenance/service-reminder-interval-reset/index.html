    Service reminder — 5,000 km interval and reset

    Tags: #dashboard · #conflict

    Community members disagree on this topic — both positions are reported.

    Fixed interval, not customizable. The factory service interval reminder on the FAW X80 is fixed at 5,000 km and cannot be changed to a different interval (e.g. 7,000 km) through the dashboard menu.123456789

    Reset procedure: 1. Press the Info button on the steering wheel to display the reminder. 2. Enter the Settings menu. 3. Navigate to Technical state of car (техническое состояние). 4. Press OK on the steering wheel. 5. Select Remaining mileage (остаток пробега). 6. Hold the Info button for approximately 3+ seconds to reset the interval.

    The reminder must be reset manually after every service — it does not auto-reset.123456789

    Additional confirmation (2025-10 report). A separate owner corroborated that pressing OK repeatedly is unnecessary — the reminder can be cleared directly via a dedicated "reset remaining mileage" option in the dashboard menu, matching the procedure above.1011

    Countdown display example (2026-03 report). The reminder counts down from the 5,000 km interval — one owner's dashboard showed "change oil in 4,100 km" when about 900 km had already been driven since the last reset, confirming the fixed-interval countdown behavior described above.1213

    Earlier-reported alternate procedure — ignition + OK-button hold method (2024-06 report; possible conflict with the Info-button procedure above). A separate, earlier community report describes a different-looking reset sequence: (1) press the INFO button briefly (lower-left of the steering wheel) to check remaining mileage to the next service; (2) after service is completed, press the OK button when the service symbol appears; (3) turn the ignition to ON while holding the OK button for a minimum of 10 seconds, until the symbol resets. After reset, the service light disappears and the INFO screen can no longer display the service interval countdown until the next cycle begins. This sequence does not exactly match the Info-button-hold-only procedure documented above — treat the two as possibly reflecting different model years/dashboard software revisions rather than assuming either is wrong, and try the Info-menu procedure first since it has broader corroboration on this card.1415

    Reset fails without a working Info button (2026-04 report). If the steering-wheel Info button itself is non-functional, the standard reset procedure above cannot be completed — there is no alternative in-dashboard method without it. In that case, an OBD2 tool or a dealer/service-center reset is the reported workaround, though this wasn't independently confirmed as fully working in this report (confidence: low).16171819
